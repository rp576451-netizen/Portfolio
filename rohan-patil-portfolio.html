Who I Am

// My Story

I'm Rohan Shashikant Patil, a first-year BTech student at MIT Academy of Engineering, Pune. I've always been fascinated by how things work — whether it's a mechanical system, a circuit, or a computer program. That curiosity is what drove me into engineering.


I'm at the beginning of my journey, but I'm deeply committed to learning by doing — building small projects, breaking things, and figuring out why.

// What I'm Learning

My coursework at MITAOE covers core programming in C and Python, data management with SQL, and fundamental engineering concepts. I've also started exploring data science libraries like NumPy and Pandas.


Outside class, I work on hands-on projects to apply what I learn — from database design to hardware experiments like building a face sensor.

// My Interests

I love understanding mechanisms — how software interacts with hardware, how data flows through systems, and how ideas become working products. I'm especially drawn to software development and emerging technologies.

Software Dev Data Analysis Databases Hardware + Code New Technologies Problem Solving
